## Work-schedule body candidates

`InsertWorkSchedule` (#26547) and `UpdateWorkSchedule` (#26551) forward caller data as POST/PUT data. Form submit handler #39305 is one locally traced constructor that supplies evidence for field candidates:

- Base object: `employee_id`, `type_id`, `start_date`, `start_time`, `end_time`, `full_day`, `is_recurring`, `repeat_end`, `rrule`, `lunch_time`, `desc`, `change_mode`, `range_end`, and `range_start` (`eliis.hasm` lines 1582886-1582966).
- **Insert: 14 own keys** on every executed observed path. Both range keys are always assigned (`1582959, 0x164` and `1582966, 0x181`), even when their values are undefined; constructor inclusion is distinct from subsequent serialization. #26526 copies at `1029996, 0x31`; service call is `1030038, 0x103`. #26547 loads data parameter 2 at `1030629, 0x30` and calls Axios POST at **`1030630, 0x33`**. `lunch_time` is `parseInt(...,10) || 0`, not a server default. Duration assignment requires captured edit flag slot 12 truthy (`1582967-1582973`); insert requires the same flag falsy (`1582978-1582979`), so **duration is excluded from insert**.
- **Update: 19-name possible-key union, not 19 simultaneous keys.** #39305 passes base register 5 and captured selectedData slot 8 to `difference` at `1583003, 0x22b`, producing register 4. #25432 → #25433 → #25434 omits equal values (`996255-996258, 0x19-0x25`, skip target `0x71`) and writes unequal values at `996276, 0x6d`, with an object recursion branch and #25436 transform accumulator. Subsequent branches restore/add/delete keys. Only **`id` and `employee_id`** are always assigned after filtering (`1583073/1583075, 0x398/0x3a4`); all other names have conditional client presence, including range keys because of filtering, not merely nullish params. Update call passes **difference register 4**, not base, at `1583085, 0x3d1`. #26530 copies the difference and calls service at `1030200, 0x19d`; #26551 reads body.id at `1030699, 0x15` and sends that same body register 3 as PUT data at `1030707, 0x39`.
- **Selected-data provenance:** duration is read from captured selectedData slot 8 (`1582969-1582973, 0x18d-0x1a2`), not submitted form data, before difference filtering. exception_date is copied from captured selectedData.start_date (`1583039-1583041, 0x2f0-0x2fa`), not freshly formatted base start_date; its type remains unknown. Update `date` and `end_date` are conditional formatted-string copies; single-branch end_date assignment is `1583032, 0x2cc`.
- **Time fields remain unknown:** #39305 full-day branch overwrites start_time/end_time with null (`1582976-1582977, 0x1af/0x1b5`). Both actions skip conversion for truthy full_day (#26526 `0x37-0x3d`; #26530 `0x3d-0x43`), so null survives to Axios. Other paths produce SDK strings. Update time keys may also be omitted by difference/branch behavior; lunch_time remains integer when present.
- **Actual UTC helper is #25412**, not #25369. M2289/#26515 dependency 3=M2228 (`11570-11573`); #25411 exports #25412 at `995548-995549, 0x84-0x89`. Helper `995603-995642` formats date/time with `YYYY-MM-DD`/`HH:mm:ss`, using today's date or `00:00:00` for falsy inputs. Its return object includes tz/date/time, but actions copy **only selected outputs into existing start_date/start_time/end_time**. Helper fields and selected repeat_start/timezone inputs do not add request date/time/tz/repeat_start keys. The update `date` field above has its separate form-branch proof, not helper provenance.

Both integrated operation bodies are partial `kind: object`, `complete: false`, preserving unresolved caller remainders. Local completeness metadata means fourteen insert own keys before serialization, or the traced nineteen-name update **possible-key union plus omission/branch mechanisms**. It never means nineteen keys coexist or that all callers are covered. Optional metadata records conditional client inclusion only, not server requiredness; an undefined insert own value is not marked optional. No server enums, defaults, nullability declarations, or date-format constraints are inferred. SDK formatting string proof follows #12925 → #12755/#12753/#12754 (string seed/concatenation/return at `512830/512849/512854, 0x10/0x55/0x67`), without guaranteeing valid dates.

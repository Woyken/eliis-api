## Minimal corrections

1. **`CreateDiary.published` type:** in the `published` body field, change `type: "unknown"` to `type: "integer"`. `#25765` directly uses `LoadConstZero` before writing the field (`0x71–0x78`), so the emitted client value is known numeric integer zero. Keep `value: 0` and the note that this is not a server default or enum.

2. **`SaveEmployeeMeal` computed-value branch:** replace wording that says null only when the value is “null” with “nullish.” `#37349` uses a non-strict null comparison and writes the computed key in either case: non-nullish `event.value` is copied; otherwise the computed property is assigned `null` (including an undefined event/value). Do not add a guessed static meal key, type, or optional field.

3. **Move-body provenance:** the key names and `unknown` types are supported, but the cited chain proves the value is `routeParams.items` copied directly into `folder_ids`/`file_ids`, not an element-wise ID mapping. In the two field/variant evidence strings, say that `routeParams.items` is forwarded unchanged unless a separate source chain proves its contents are IDs. Do not upgrade the values to `unknown[]` without array/element proof. The destination `folderId` is independently used in the route, not the body.

4. **Document `edit` condition semantics:** keep `edit.optional: true`, but replace “edit-permission condition” / “client permission behavior” with “ACL-response-shape condition.” In `#39650`/`#39655` (lines 1597993 and 1598264), the state guarding `#39657` is set from `!Array.isArray(getDocumentAclResponse)`: array responses populate `viewTargetGroups` and omit `edit`; non-array responses populate `view`/`edit` form state and enable the edit branch. `#39657` then writes `edit` only when that state is truthy. This proves conditional client construction, not an authorization decision or server ACL contract. Field type `unknown` remains appropriate; do not infer an array type from the UI controls.

The `{fileId}` placeholders on the three metadata paths describe dynamic route segments; the traced callers pass a property named `filename` through those segments. The route shapes are correct, and this review does not treat that placeholder label as proof of a server-side ID type. Diary/gallery `filename` and kindergarten identifiers remain routing-only; document `filename` stays in the body because the same form object is forwarded unchanged.
